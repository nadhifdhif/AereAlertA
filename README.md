# AéreAlertA

AéreAlertA is a web-based IoT air monitoring and environmental control system designed to collect, visualize, and analyze environmental sensor data in real time.

The system is planned to support air-quality monitoring, environmental recommendations, device control, alerts, and AI-assisted analysis.

## Tech Stack

- Laravel 13
- Vue 3
- Inertia.js 3
- Tailwind CSS
- Vite

## Planned Features

- User management
- IoT device management
- Real-time environmental monitoring
- Temperature and humidity monitoring
- Air quality and gas monitoring
- Interactive monitoring dashboard
- Historical sensor data and charts
- HMI-based device control
- AI-assisted environmental analysis
- Weather data integration
- Email and WhatsApp alerts
- Live camera monitoring

## Sensors

Initial sensor support includes:

- DHT22
- MQ-2
- MQ-135

Additional sensors may be added during development.

## Architecture

AéreAlertA uses a **modular monolithic architecture**, with Laravel as the main application framework and Vue.js integrated through Inertia.js as the presentation layer.
