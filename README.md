# AéreAlertA

AéreAlertA is a web-based IoT air monitoring and environmental control system designed to collect, visualize, and analyze environmental sensor data in real time.

## Tech Stack

- Laravel 13
- Vue 3
- Inertia.js 3
- Tailwind CSS
- Vite

## Sensors

Initial sensor support includes:

- DHT22
- MQ-2
- MQ-135
- pH Sensor

Additional sensors may be added during development.

## Architecture

AéreAlertA uses a **modular monolithic architecture**, with Laravel as the main application framework and Vue.js integrated through Inertia.js as the presentation layer.
